# 🍕 Pizzashi - Masaüstü Sipariş Yönetim Otomasyonu

Pizzashi, Python ve PyQt5 kullanılarak nesne yönelimli programlama (OOP) prensipleriyle geliştirilmiş, CRUD (Ekle, Oku, Güncelle, Sil) tabanlı bir masaüstü sipariş yönetim sistemidir.

Projeyi üniversitemdeki python programlama dersinin final projesi olarak yaptım.

### 🚀 Öne Çıkan Mühendislik Pratikleri
- **Modüler Mimari:** Qt Designer ile tasarlanan arayüzler ayrı "_ui.py" dosyalarında tutulmuş, ana işleyiş ve sinyal/slot mekanizmaları "main.py" içindeki sınıf yapılarında yönetilmiştir.
- **Nesne Tabanlı Programlama (OOP):** Her bir pencere kendi sınıfı içinde kapsüllenmiş ve ana menü üzerinden kontrol edilmiştir.
- **CRUD Operasyonları:** Sistem üzerinden anlık olarak yeni sipariş oluşturulabilir, mevcut siparişler listelenebilir, malzemeler güncellenebilir ve sipariş iptali yapılabilir.

### 🛠️ Teknolojiler
- **Dil:** Python 3
- **GUI Framework:** PyQt5
- **Mimari:** Modüler OOP, Event-Driven Programming

### 🎮 Nasıl Çalıştırılır?
1. Repoyu bilgisayarınıza klonlayın: "git clone https://github.com/Yexsea/Pizzashi-Otomasyon.git"
2. Gerekli kütüphaneyi kurun: "pip install PyQt5"
3. Ana dosyayı çalıştırın: "python main.py"
